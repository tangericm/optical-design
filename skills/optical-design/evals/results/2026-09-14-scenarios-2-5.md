Ground truth: objective EFL 7.856 mm, tube-lens-side pupil 8.076 mm, image-space NA 0.516
(marginal ray, n sin theta) which equals the paraxial EPD / 2f = 0.514 within the sine
condition. Relay entrance pupil 4.0 mm.

baseline agent trusted a hand-traced ray without checking it against EPD / 2f.

## Method notes

- With-skill agents can read `evals/evals.json` inside the installed skill; scenario 2's
  with-skill run did. Keep future runs honest by excluding `evals/` from the installed
  copy or by holding the assertions outside the repository.
- Agent tokens per run were 99 k to 126 k in every case; time, not tokens, is where the
  skill saves.
